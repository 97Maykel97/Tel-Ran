# Course Catalog

Учебный проект на React и Vite. Приложение отображает каталог курсов и позволяет открыть подробную информацию о выбранном курсе.

## Возможности

- Отображает список курсов из локальных данных.
- Показывает название курса, преподавателя, продолжительность, стоимость и доступность.
- Использует условный рендеринг для статуса доступности и пометки премиального курса.
- Показывает сообщение, если список курсов пустой.
- Открывает модальное окно при клике на карточку курса.
- Показывает кнопку записи только для доступных курсов.
- Использует переиспользуемый компонент `Card` с `children`.
- Использует SCSS Modules для изолированных стилей компонентов.

## Технологии

- React
- Vite
- JavaScript
- Sass / SCSS Modules

## Запуск проекта

Установить зависимости:

```bash
npm install
```

Запустить сервер разработки:

```bash
npm run dev
```

Собрать production-версию:

```bash
npm run build
```

## Поток данных

`courses.js` экспортирует массив курсов. `App` передаёт его в `CourseList`, который с помощью `map()` создаёт компоненты `CourseCard`. При клике на карточку выбранный курс передаётся обратно в `App`, после чего открывается `CourseModal`.

## Примечание

Кнопка записи пока является только элементом интерфейса: она не сохраняет регистрацию и не отправляет данные на сервер.
