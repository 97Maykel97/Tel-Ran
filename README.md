# Students CRM

Учебное приложение на React и Vite для отображения локального списка студентов.

## Возможности

- Список студентов хранится в статическом массиве.
- Каждый студент имеет уникальный `id`, имя, возраст и статус обучения `isActive`.
- Карточки студентов выводятся через отдельные React-компоненты.
- Статус обучения выделяется цветом: активный студент и обучение на паузе.
- Несовершеннолетний студент отмечается отдельной меткой.
- Количество студентов вычисляется через `students.length`.
- Компонент списка умеет показывать сообщение для пустого массива.

## Запуск

Установить зависимости:

```bash
npm install
```

Запустить режим разработки:

```bash
npm run dev
```

Собрать production-версию:

```bash
npm run build
```
